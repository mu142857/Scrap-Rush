# 第二夜：早上先看这里

作者睡前说："你开始做武器，就是挂机跑……早上我最好看到一些很好的场景"。所有改动都没提交。

## 做完的
1. **四把新武器**，开局 7 选 1，商店里花 3 个零件可以换：
   - 废铁散弹枪（游戏设计）：贴脸一扇 7 颗，后坐力就是位移，空中朝下开火能往上弹。Boss 44/57/65 秒。
   - 显像管激光（游戏设计）：充能 0.9 秒，一道光束横穿全屏、无限穿透，顺带烧掉线上的 Boss 子弹。Boss 49/54/72 秒。
   - 唱片回旋镖（总机台会话）：去回都割，碰墙弹一次，接住下一张更快。Boss 46/53/70 秒。
   - 特斯拉电钳（布谷鸟钟会话）：按住自动劈最近的怪再跳 3 只，小怪会麻。Boss 44/49/64 秒。
2. **选武器界面**改成 7 格加说明面板，双人左右分开各选各的。
3. **图鉴武器册**补齐 7 把，小动画全是代码画的。
4. **制作人员页**：去掉了大动画，改成电影胶片效果，每页配现成的画面（第一关视差、开场帧、梧桐立绘、锅炉房、小怪排队、结局的家）。包体比昨晚发的版本小约 3.6MB。
5. **质检**：7 把武器各单人通关三关加三个 Boss，双人两种组合通关，20 组武器加变异 0 报错，没有发现新武器的 bug。
6. 守夜巨人、剪辑师贴墙躲不开的招已修。

## 要你定的
1. 第一关布谷鸟钟、自动钢琴用任何武器都只要 11～13 秒，要不要加血。
2. 第三关精英血量要不要再 ×1.3（小怪平衡以后第三关单场还是比第二关快）。
3. 商店"装备按等级涨价"开不开（upgrades.gd 的 tiered_gear_price）。
4. 环境声降了采样率，要你在第一关或商店听一圈循环有没有咔哒声。
5. 武器合成系统和更多变异：你说先不管，等你想做再说。
