# 像素字体的署名和授权（给「游戏细节讨论」做 CREDITS 页用）

中文模式会话整理，2026-10-18。来源：字体文件自带的版权信息（name 表），以及字体里写的文泉驿 README
（原文已存进 `oscar-rush/tools/fonts/WenQuanYi_README.txt`）。

1. **正式名字**：中文「天王星像素 11Px」，英文「Uranus Pixel 11Px」（字体里写的版本是 "Version 0.99 & Final"）。
2. **作者 / 维护者**：字体文件没写 Uranus Pixel 是谁做的（只有厂商代码 FANC）→ **待查**。
   版权行写的是：文泉驿信任委员会（The WenQuanYi Project Board of Trustees）、FangQ、Firefly。
3. **来源网址**：字体里只给了文泉驿点阵宋体 TTF 版的仓库 https://github.com/AmusementClub/WenQuanYi-Bitmap-Song-TTF ；
   Uranus Pixel 自己的发布页 → **待查**。文泉驿项目主页：http://wenq.org/
4. **基于**：文泉驿点阵宋体（WenQuanYi Bitmap Song）11px，里面含 Firefly 点阵字形。
   原版版权：© 2004-2010, The WenQuanYi Project Board of Trustees and Qianqian Fang（方倩倩，项目创立者和维护者）。
5. **授权**：GNU GPL v2，附字体嵌入例外（font embedding exception）。
   - 游戏包里带着字体文件，按 GPL 要附上授权说明。建议：CREDITS 页写署名，再给出 GPLv2 链接
     https://www.gnu.org/licenses/old-licenses/gpl-2.0.html ；网页版或 itch 页面上也放一份同样的说明。
   - 我们用的是**改过的版本**：裁成只含常用字和用到的字，并调了空格和几个英文标点的间距（`tools/subset_font.py`）。
     改过的字体也必须按 GPLv2 发布，署名里要写明"改过"。字体文件本身就是它的源码，有人要就给，比如放一个下载链接。

## 建议的署名写法
英文：
> Pixel font: Uranus Pixel 11Px, based on WenQuanYi Bitmap Song.
> © 2004-2010 The WenQuanYi Project Board of Trustees and Qianqian Fang; FangQ, Firefly.
> GNU GPL v2 with font embedding exception. Modified for this game (subset, spacing).

中文：
> 像素字体：天王星像素 11Px，基于文泉驿点阵宋体。
> © 2004-2010 文泉驿信任委员会、方倩倩（Qianqian Fang）、FangQ、Firefly。
> GNU GPL v2 授权（附字体嵌入例外）。本游戏用的是改过的版本（只保留用到的字，调了间距）。

## 请作者留意（不是急事）
- 字体嵌入例外的原文是"embed this font **or unaltered portions** of this font"。我们改了空格和标点的间距，
  严格说已经不是"原封不动的一部分"。图稳妥的话可以二选一：
  (a) 保持现在这样，把改过的字体当成一个 GPLv2 组件，附上授权和字体文件（上面的写法就是按这个写的）；
  (b) 把 `tools/subset_font.py` 里调间距的两步关掉（只裁字，不改字形），英文空格改用 Godot 的 FontVariation 加宽，
      标点那一项就放弃。
- README 里写着"商用请联系维护者（Qianqian Fang）或者咨询律师"。Jam 版没问题；以后要发 B 站，如果涉及收益，最好先确认一下。
- 工程里原来没有任何字体授权文件。现在 `oscar-rush/tools/fonts/` 里有原字体和 `WenQuanYi_README.txt`（tools/ 不进导出包）。

## 看了制作人员页（credits_menu.gd）以后的两点（2026-10-18）
- 现在写的是 "Pixel font: Uranus Pixel 11Px, based on WenQuanYi Bitmap Song 11px." —— 建议补一句我们改过：
  "... Subset and spacing modified for this game."（中文：本游戏用的是改过的版本：只保留用到的字，调了间距。）
- 授权页那句 "embedding the font in a document **or game** does not by itself make that work covered by the GPL"：
  原文的例外只说 document（文档），"or game" 是我们自己的理解，写成原文的样子更稳妥：
  "As a special exception, if you create a document which uses this font, and embed this font or unaltered portions of this font
  into the document, this font does not by itself cause the resulting document to be covered by the GNU General Public License."
