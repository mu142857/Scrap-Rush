## 6. 双人模式的经济和马灯（测完，数值没改）

双人时，马灯、零件、武器、装备、变异都是两个人共用。怪的数量不随人数变。马灯上限随人数降：1 人 100、2 人 80。清场回血 +12、灯油 +4、商店修灯 +25 是固定数，所以按比例算，双人回得更多。

测法：站着不动的机器人（对着最近的怪一直打，不躲），打第一关前 4 场遭遇战，单人和双人各跑一遍。场与场之间按走路 25 秒补情绪。站着不躲比真人难得多，只用来比较单人和双人。

| 武器 | 单人 | 双人 |
|---|---|---|
| 铆钉枪 | 4 场打完剩 58/100，每场掉 6～44 | 剩 74/80，前 3 场一滴没掉 |
| 闪光灯 | 第 3 场碎 | 前 3 场一滴没掉，第 4 场（吸尘器精英）碎 |
| 蒸汽锤 | 第 2 场碎 | 第 4 场碎；情绪一路涨到 90～100 |

结论：
- 马灯：双人明显更松。拿灯的人有队友挡怪，一场也快 25% 左右（15 秒对 20 秒）。
- 情绪：双人和单人差不多，有时更高。没拿灯的人挨一下就 +8，两个人都在挨打。用蒸汽锤要贴脸，涨得最快。
- 零件和商店：两个人共用，零件也一样多。买的升级是两个人一起生效，所以不存在"两个人要买两份"的问题，不用改价。
- 不改数值的原因：双人马灯更松，情绪又更容易高，两头差不多抵消。双人本来就该轻松一点。

如果作者觉得双人马灯太没压力，有两个方向，都要改别人的文件，所以先不动：
- 怪优先追拿灯的人。
- 双人时清场回血降到 8。

另外顺手修了一处：镀层（每隔 10～20 秒挡一次马灯伤害）原来也按现实时间计时，和从闪是同一个问题，现在改成按物理帧算（upgrades.gd）。

## 10. 情绪档位的音频和混音（改了 emotion_fx.gd 一个音量）

算法：每个音效文件"最响 100 毫秒"的音量，加上混音会话在 Game.sfx 里统一做的修正，再加上调用时写的音量。

| 声音 | 实际音量 |
|---|---|
| 参照：主角受伤 hurt | -15.9 dB |
| 参照：普通射击 shoot | -16.4 dB |
| 参照：铆钉 | -17.4 dB |
| 参照：清场 | -17.4 dB |
| 升档：电视咔哒 + 雪花 | -16.0 / -28.6 dB |
| 回血 ding | -18.0 dB |
| 发电机回血 buzz | -20.2 dB |
| 失控心跳（每 0.55～0.75 秒） | -21.2 dB |
| 捡灯油 | -21.1 dB |
| 降档 ding | -22.0 dB |
| 过载警报（每秒），改前 | -26.0 dB |
| 过载警报，改后 | -22.0 dB |
| 从闪补射 / 回声出招 | -28.4 / -30.4 dB |

结论：
- 升档那一下和战斗声一样响，是故意的事件提示。
- 持续的声音（心跳、警报）比战斗声低 4～6 dB，不抢戏。
- 只有一处反了：混音给警报统一降了 8.4 dB 以后，过载警报只剩 -26 dB，比失控心跳还轻，可过载比失控更危险。调用音量从 -14 提到 -10，现在约 -22，和心跳差不多。
- 回声、从闪补射比自己出招轻 12～14 dB，听得出是"跟着的那一下"，不改。
- 商店新加的进门火声 -22.5、零件落下 ding -26，都在提示音的范围里。

## 11. 情绪对怪的影响（改了 enemy_base.gd、emotion_fx.gd；crawler.gd 改了几行，已经跟游戏设计会话打过招呼）

查下来：
- 爬虫完全没接情绪倍率：速度固定 18，碰人伤害固定 10。它是第一关最多的怪，所以第一关里升档基本感觉不到怪变了。
- 其他新怪大多接上了：剃须刀、跳蚤、飞蛾、胶片盘的速度和出招间隔，汽壶的喷汽间隔，精英的出招。所有新怪碰人的伤害也都乘了倍率（EnemyBase 里统一做的）。
- 但玩家看不出来：红灯在每一档都是同一个颜色、同一个闪法。

改动：
- 爬虫：速度乘 speed_mult（平静 ×1 → 失控 ×1.5），碰人、碰灯的伤害乘 damage_mult（×1 → ×2）。
- 所有怪的红灯跟着档位变：
  - 平静：一秒闪 3 下，暗红。
  - 烦躁：一秒闪 4 下。
  - 愤怒：一秒闪 6 下，偏橙、更亮。
  - 失控：一秒 12 下，在白热和红之间狂闪。
  - 小怪那圈红光的亮度从 0.9 加到 1.7，范围也跟着变大。精英自己管红光（出招前先亮），没动。
- 每次升档，场上所有怪一起白闪一下，像是"它们也听到了"。

验证：
- headless 实测爬虫：情绪 0 时每秒 18.1 像素、红光 0.9；情绪 90 时每秒 27.2 像素、红光 1.7、红灯白热。

## 12. 难度曲线模拟（只出报告，数值没改）

### 做法和局限
1. **整局机器人**（第一关 → Boss1 → 商店 → 第二关 → Boss2 → 商店 → 第三关路线 0 → 商店 → Boss3）。

- **难度曲线是倒的。** 单场强度第一关最高：平均 9 只怪、2000 血，桥上那场 16 只、3500 血，是全游戏最重的一场。第二关差不多。第三关每场只有 5 只、1400 血，最轻。

1. 第三关的清场回血按场子大小给：每场 12 × 怪数 / 9，5 只怪的场子回 7 左右。或者第三关每场多一波小怪，让单场强度不低于第一关。

## 16. 老电视滤镜的随机数（改了 emotion_fx.gd 着色器里一个函数）

## 22. 过载到底每秒掉多少（质检报：过载 20 秒马灯 100 → 41）

结论：不是 bug，过载本身就是每秒 1，多出来的是同时在挨打。
- headless 复现：第一关开头，情绪一直顶在 100，不躲：
  - 前 15 秒周围没有怪：100 → 85，正好每秒 1.00。
  - 后 5 秒两只爬虫走到身边：又掉了 45，其中过载 5，挨打 40。
  - 20 秒一共 100 → 40，和质检的 41 对得上。
- 挨打为什么这么疼：失控档（情绪 75 以上）怪的伤害 ×2，爬虫一下从 10 变 20，挨两下就是 40。
- 没有重复扣：灯提在手上时，怪碰到灯本身不扣（Crystal.take_hit 里挡掉了），只有通过人扣的那一下。场上也只有一个 EmotionFx，过载扣血没有叠加。
- 所以"过载 20 秒掉六成"是"过载 20 + 失控档挨两下 40"，不是过载本身狠。已加进最前面的拍板清单第 9 条。

## 27. 小怪血量按每场同屏怪数重平衡（作者要求；改了 12 个小怪脚本各一行 + l3_mob.gd 两处，都先打过招呼）
