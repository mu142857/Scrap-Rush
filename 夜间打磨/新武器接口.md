## 2. 你们要做的（以唱片为例，电钳把 record 换成 tongs）

1. **出招脚本**：`scripts/combat/weapons/record.gd`，`extends WeaponHandler`。登记表里 handler 路径已经写好就是这个。
   - 写 `attack(delta)`：读 `p.attack_pressed()` / `p.attack_held()`，打出子弹。
   - 写 `draw(c)`：画枪口火光、手上的东西（c 是主角本人，坐标是主角本地，脚底 (0,0)）。
   - 写 `cancel()`：停掉蓄力、循环音。记得调 `super()` 或自己把 `p.charging` 设回 false。
   - 需要的话写 `glow()`（身上多亮，0~1）和 `move_mult()`（按住时走路速度）。
2. **子弹脚本**：`scripts/combat/weapons/record_disc.gd` 之类，随便起名，放在 `weapons/` 里。
3. **不要在 handler 或子弹里写 `Player` 这个类名**（player.gd 会加载它们，互相引用 Godot 会卡死）。主角就用 `p`（CharacterBody2D），调这些公开接口：
   - `p.attack_held()`、`p.attack_pressed()`：按住 / 刚按下（眩晕时都是 false）
   - `p.find_target()`：自动瞄准最近的怪（会画准星），返回 Node2D 或 null；`p.clear_target()`
   - `p.aim_dir(from)`：从 from 指向目标的方向，没目标就是正前方，顺手转身
   - `p.target_point(n)`：怪的瞄准点
   - `p.muzzle(dx, dy)`：枪口位置
   - `p.recoil(Vector2)`：后坐力；`p.pop(squash, light)`：出手时身子压一下、灯亮一下
   - `p.quick_level()`："快充"升级 0~3，自己决定怎么变快
   - `p.facing`、`p.strip_color`、`p.is_on_floor()`、`p.get_parent()`（子弹加到这里）
   - 蓄力 / 放电时 `p.charging = true; p.charge = 0~1`（扑灯蛾会扑、走路按 move_mult 变慢），停了设回去
4. **变异**：每打出一发调 `Mutations.on_weapon_fire(p, "record", [子弹节点...], refire)`。
   - `refire` 是 `func(dmg_mult: float, color: Color)`，回声 0.3 秒后调它：在主角现在的位置按原方向再打一发，伤害乘 dmg_mult，颜色用 color，打出来的节点 `set_meta("mutation_copy", true)`。
   - 子弹节点要有 `damage` 属性（怒火会乘它）。
   - 射得快的武器（每秒 3 发以上）请在登记表把 `echo_every` / `slave_every` 调大（电钳已经是 3 / 4，照铆钉枪）。
5. **打中**：`body.call("hurt", damage, dir, full)`（full = 重击，击退大），然后 `HitFx.after_hit(body, 位置, 方向, power)`（power 0~1：命中星大小、溅射多少；打死会自动出白剪影、碎片、溅油或溅血、连杀音高）。
   - 只打 `is_in_group("enemy") and has_method("hurt")` 的；单向平台挡不住子弹的写法见 rivet.gd 的 `Player.is_one_way_body`——你们不能写 Player，用 `body is CollisionObject2D` 加 one_way 判断，或者 collision_mask 只要 4（怪）+ 1（墙）就行。
   - Boss 子弹：要消掉的话调 `n.call("fizzle", 方向)`（会碎散，别直接 queue_free）。
6. **登记表**：做好以后把自己那行的 `"ready": false` 改成 `true`（选武器界面、商店才会摆出来）。卡片说明、特性、提示这些英文我先写了，想改直接改自己那一行。只改自己那一行。
7. **text.csv**：登记表里的英文（name、card、trait、hint、coach、shop）每条都要在 `localization/text.csv` 里加一行中文。键名就是英文原文，`\n` 照原样写成两个字符，整行带逗号的用双引号包起来。
   - 多个会话都在往 text.csv 末尾加行：**用一次性的脚本追加，追加前先检查有没有同名的键**，别整份重写。
   - 加完告诉中文模式会话。
8. **音效**：`tools/gen_sfx.py` 末尾加函数，**用自己的随机数种子**（照 `kill_pop` 的 `_rn(d, seed)`），只重生成自己的：`python3 tools/gen_sfx.py 你的音效名`。
9. **图鉴**：武器页在 `scripts/ui/codex_weapons.gd`（立绘会话的文件），每把要一段示意动画。做好后告诉立绘会话，让它照游戏实拍加。
10. **测试**：
    - 限时编译检查（--log-file 到自己的 scratchpad）。
    - 开局选你的武器：`Upgrades.weapon = "record"`（测试脚本里在第 3 帧以后设，Run._ready 会重置）。
    - Boss 打死时间：`tools/qa/elite_regression.gd` 我会改成跑登记表里所有 ready 的武器；改好前可以用 `--only=boss1,boss2,boss3` 加你自己的测试脚本。
    - 不 commit。
