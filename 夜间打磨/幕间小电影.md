# 幕间小电影（2026-10-19，游戏剧情主题讨论会话）

作者："然后结束的时候，或者每一关结束，要不要搞一个像开头一样的小电影？短一点都可以"

## 是什么
- 用序章那一套胶片（齿孔带、棕褐色、划痕、放映机"咔"），不加新贴图，画面用现成的关卡图。
- 三段：

| 种类 | 什么时候放 | 画面 | 字幕 | 时长 |
|---|---|---|---|---|
| boss1 | 打完 Boss1、进商店前 | 锅炉房 → 胶片机房 | 锅炉熄了。再往上走，电话还在响。 | 约 7.9 秒 |
| boss2 | 打完 Boss2、进商店前 | 胶片机房 → 第三关电视墙 | 胶片烧完了。再往里，一整面墙的电视还亮着。 | 约 7.9 秒 |
| finale | 结局"剧终"按键后、结算前 | 倒带：Boss3 屋子、电视墙、机房、锅炉房飞快闪回，左上角闪 <<，停在家 | 门廊的灯，一直亮着。 | 约 8.9 秒 |

- finale 和序章最后一句"去看看门廊的灯还亮不亮"首尾呼应，不重复结局里老电视开机那一下。
- 任意键 = 下一格；Esc / 手柄 Start = 整段跳过（只跳这段，照常往下走，不回主菜单）。
- "继续游戏"从下一关开头接着打，不经过幕间。

## 文件
- `scripts/ui/interlude.gd`（继承 `prologue.gd`）、`scenes/interlude.tscn`。
- `prologue.gd` 改成用变量 `shots`、`roll_time`，加了 "wall" 一种画面；序章本身行为不变。
- 接入（各一行）：
  - `scripts/boss/boss_arena.gd` 的 `_leave()`：`Interlude.route(scene_file_path, "res://scenes/shop.tscn")`；
  - `scripts/levels/boss3_room.gd`：`Interlude.route("finale", "res://scenes/results.tscn")`。
- `Interlude.route(种类或 Boss 场景, 目的地)`：有对应的一段就返回幕间场景（放完去目的地），没有就原样返回目的地。
- 3 句字幕已进 `localization/text.csv`（英文里有逗号的要加引号）。

## 测试
- 单放一段：`Godot --headless --fixed-fps 60 --path . res://scenes/interlude.tscn -- --ikind=boss1`（boss2 / finale），放完打印 `interlude <种类>: done at …`。
- 整条结局链：`scenes/ending_test.tscn -- --chain`：结局 → finale → 结算 → 回标题，统计清零。
