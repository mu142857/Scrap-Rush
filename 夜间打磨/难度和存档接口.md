# 难度和存档接口（游戏设计会话，10-18）

作者：「选择关卡的换成选择难度」「继续游戏」「每进一关存一次」。代码都在 `scripts/autoload/run.gd`（Run 自动加载）。

## 难度
- `Run.difficulty`：0 简单、1 普通（原来的数值）、2 困难。**选难度界面在开新局前设它**；新开一局（reset_run）不重置，记住上次选的。
- `Run.DIFFICULTY_NAMES`：["EASY", "NORMAL", "HARD"]（英文，界面上要 tr，中文请加进 text.csv）。
- 三个倍率（已经接好，别处不用再改）：

| | 简单 | 普通 | 困难 | 接在哪 |
|---|---|---|---|---|
| 马灯受伤 `damage_taken_mult()` | ×0.6 | ×1 | ×1.3 | Run.damage_crystal（所有扣马灯的地方都走它：挨打、Boss、吸尘器、第二关烧胶片、第三关信号、情绪过载） |
| 怪血 `enemy_hp_mult()` | ×0.8 | ×1 | ×1.3 | EnemyBase._ready（小怪、精英、第三关怪）、Crawler、BossArena（三个 Boss） |
| 马灯回血 `heal_mult()` | ×1 | ×1 | ×0.7 | Run.heal_crystal（清场、灯油、发电机） |

- 商店修灯（shop_room.gd 直接加 crystal_hp）没走 heal_crystal，难度不影响。商店会话要不要让困难修得少，你们定。

## 存档
- 存在 `user://run.cfg`。**测试时设环境变量 `SCRAP_RUN_PATH=别的文件`**，不碰作者的存档。
- 保护（10-18 晚加）：只有"正常开的游戏"才写 user:// 下的文件——正式导出的游戏或编辑器里按运行，并且从主场景（开始菜单）开起来，并且不是 headless / 录像 / 带 -- 测试参数。直接打开关卡场景、-s 测试脚本、命令行测试一律不写（设了 SCRAP_RUN_PATH 的照常写到那里）。判断在 `Run.real_launch()`，图鉴（bestiary.gd）、打到第几关（progress.gd）也改成用它。clear_save 同样受保护，测试删不掉作者的存档。
- 什么时候存：每进一关自动存一次——三关各自的第一个场景（test_level、level2_tube、level3）走 `Run.start_level()` 时；从存档点重来不存。
- 存了什么：难度、第几关（和那关开头的场景）、零件、四项升级、变异、P1 武器、马灯血量（占满血的比例）、每个玩家（输入方案、角色、武器）、这一局的统计（时间、死几次、花了多少零件）。

### 给开始菜单（游戏细节讨论会话）
- `Run.has_save() -> bool`：有没有存档（决定"继续"按钮亮不亮）。
- `Run.save_info() -> Dictionary`：`{level: 1~3, difficulty: 0~2, players: 人数, weapons: [每人武器 id], saved_at: "2026-10-18T18:46:27"}`，没存档返回 `{}`。按钮下面可以写"第 2 关 · 困难 · 双人"。
- `Run.continue_run() -> String`：把存档读回来（难度、人、武器、零件、升级、变异、马灯），**返回要进的场景路径**；调的人自己切场景：`SceneFade.go(get_tree(), Run.continue_run())`。不要再调 reset_run（continue_run 里已经调过）。
  - 继续不经过选武器界面（武器存在存档里）。
  - 存档里的手柄（pad0、pad1）如果现在没插，进游戏后那个人动不了；需要的话开始菜单先检查一下。
- `Run.clear_save()`：删掉存档。建议：选「新游戏」时如果有存档，先确认"会覆盖"，确认后 clear_save；通关以后要不要删，你们定（不删的话继续会回到第三关开头）。
- 新游戏的流程不变：设 Run.players → Run.reset_run() → 设 Run.difficulty → 选武器 → 第一关（进第一关时自动存）。

### 给商店会话
- 商店里买的升级、变异、零件都会在下一关开头存进去，不用你们做什么。
- 武器以后不卖了（作者定的），存档里的武器是开局选的那把，或者布谷鸟钟会话做的"精英掉武器"换的那把——都走 `Upgrades.set_weapon_for`，存档自动跟上。
