## 1. 目录约定

## 2. 关卡怎么搭（骨架，我来做）
- 一个场景 `scenes/hidden/hidden_level.tscn`（脚本 `HiddenLevel`），所有房间都在里面。
- **每个房间是一块独立区域**：位置按总图摆，1 屏 = 480×270，房间之间不连通。**走进门 = 瞬移到下一个房间的入口**，中间放一下录像带"跳带"的转场（0.25 秒）。所以房间大小、地面高度互相不用对齐。
- 镜头：用第三关的 `Level3Camera`，每个房间是一块"屏幕"，锁在当前房间里。
- 房间数据由 `草图/隐藏关/export_hidden.py` 从 `草图/隐藏关/rooms.py` 生成 `scripts/hidden/hidden_data.gd`，照第二关 `level2_map.py` 的做法。**别手改 hidden_data.gd**，要改房间就改 rooms.py 重新导出，或者告诉我。

### 2.1 房间数据（`HiddenData.ROOMS[id]`，坐标都是世界坐标、像素）
```
"R6": {
  "name": "派对", "zone": "Z2",
  "rect": Rect2(…),            # 整个房间
  "floor": 1234.0,             # 主地面的 y
  "mech": "pause",             # "" / "pause" / "skip" / "rewind" / "exam"（三样都有） / "boss"
  "fight": true,               # 有没有关门的遭遇战
  "solids": [Rect2, …],        # 中性实心（任何时候都能站）
  "memory": [[x0, x1, y], …],  # 回忆平台（暖，单向平台，光里才实）
  "junk": [[x0, x1, y], …],    # 覆盖层废铁（冷，单向平台，暗处才实）
  "junk_walls": [Rect2, …],    # 覆盖层的墙（暗处是墙，光里消失）
  "frame_a": [[x0, x1, y], …], # 跳帧 A 帧平台 / "frame_b" 同
  "pause_buttons": [Vector2, …],
  "hazards": [[x0, x1, y], …], # 雪花带（静态的位置，会不会动由机制或美术决定）
  "rings": [[cx, cy, r], …],   # 转动的回忆平台（摩天轮、气球）
  "waves": [["dust_moth", "dust_moth"], ["spool"]],  # 遭遇战的波次（小怪）
  "roam": [{"kind": "dust_moth", "pos": Vector2}],    # 不关门的散怪
  "elite": "music_box",        # 遭遇战最后一波的精英（"" 表示没有）
  "boss": "",                  # "rec" 只有 R17
  "doors": [{"rect": Rect2, "to": "R7", "at": Vector2, "lock": ""}],
  "pickups": [{"kind": "photo"|"part"|"clip", "id": "p1", "pos": Vector2}],
  "checkpoint": Vector2 或 null,
}
```

### 2.2 房间节点 `HiddenRoom`（每个房间一个，挂在关卡下）
- `id: String`、`rect: Rect2`、`data: Dictionary`（就是上面那份）、`level: HiddenLevel`
- `active: bool`：有主角在这个房间里。`signal entered` / `signal exited`
- `actors() -> Array[Node2D]`：房间里的怪（group `enemy`）和所有飞行物（BossBullet 以及其他 `Area2D` 子弹，group `hidden_projectile`）。**你们的子弹请加进 group `hidden_projectile`**，倒带、暂停才找得到。
- `plats(kind: String) -> Array[HPlat]`：kind 是 `"memory"`、`"junk"`、`"a"`、`"b"`
- `fight: Encounter`：这个房间的遭遇战（没有就是 null）

### 2.3 平台节点 `HPlat`（`scripts/hidden/h_plat.gd`）
- `kind`：`"memory"` / `"junk"` / `"a"` / `"b"`
- `solid: bool`：只读，当前是不是实的
- `frame_on := true`：跳帧用。a / b 平台只看这个，不看光。跳帧机制每次换帧时设它
- `force := 0`：机制或 Boss 用。`1` 强制实，`-1` 强制虚，`0` 照规则
- 碰撞：单向平台，碰撞层 `HiddenLevel.PLAT_LAYER`（64，和第三关的家具平台同一层），只有主角和马灯会踩。怪不踩这些平台，走中性地面。

## 3. 灯照回忆：`MemoryLight`（`scripts/hidden/memory_light.gd`，静态类）
| 调用 | 用途 |
|---|---|
| `MemoryLight.is_lit(pos: Vector2) -> bool` | 这个点在不在光里。怪和机关用这个判断"在不在光里" |
| `MemoryLight.amount(pos) -> float` | 0～1，越靠近光源越接近 1（画效果用） |
| `MemoryLight.add_temp(pos, radius, sec)` | 临时光：比如八音盒光束、摄像机补光灯、遥控器红外 |
| `MemoryLight.add_segment(a, b, width, sec)` | 一条线状的光（激光、光束） |
| `MemoryLight.add_node(node, radius)` / `remove_node(node)` | 跟着一个节点走的持续光源（精英、Boss 身上的灯） |
| `MemoryLight.lantern_scale` | 马灯光圈倍率。磁粉蛾啃光圈就改这个：`MemoryLight.bite(0.1)` 减、`restore(0.1)` 加，夹在 0.5～1 |

- **关卡每物理帧自动加的光源**（不用你们管）：
  - 马灯（手上或地上），半径 90 × 情绪倍率 × lantern_scale；
  - 闪光灯光球（Orb）；
  - 显像管激光的光束；
  - 特斯拉电钳按住时（主角身边半径 40）；
  - 从闪补射的小光球。
- 平台的判定由关卡每帧刷新，`HPlat.solid` 反映结果。

## 4. 怪和精英怎么接
**小怪**（总机台、留声机会话）
- 写在 `scripts/hidden/enemies/`，**继承 `EnemyBase`**，照第三关 `L3Mob` 的路子。
- 工厂 `scripts/hidden/hidden_mobs.gd`：
  ```
  class_name HiddenMobs
  static func exists(kind: String) -> bool
  static func make(kind: String) -> EnemyBase
  ```
- kind 固定五个：`dust_moth`（磁粉蛾）、`spool`（卷带虫）、`remote`（遥控器）、`rewinder`（倒带鬼）、`tracking`（跟踪条）。
- 关卡出怪：遭遇战的 `spawn_hook` 调 `HiddenMobs.make(kind)`，散怪也调它。出生位置由关卡给。
- 卷带虫抽出的磁带要变成一段临时的冷色废铁平台，调 `HiddenLevel.cur.add_temp_plat("junk", x0, x1, y, sec)`。
- 倒带鬼要"主角 3 秒前在哪"，调 `HiddenLevel.cur.player_trail(p: Player, sec_ago: float) -> Vector2`（关卡给每个主角记 4 秒轨迹）。

**精英**（布谷鸟钟会话）
- 写在 `scripts/hidden/elites/`，**继承 `EliteBase`**（第三关精英那套，名字卡、血条都现成）。
- 工厂 `scripts/hidden/hidden_elites.gd`：`class_name HiddenElites`，`make(kind) -> EliteBase`。
- kind：`music_box`（八音盒 R7）、`snow_globe`（雪花球 R10）、`camcorder`（摄像机 R14）。
- 关卡把它放在遭遇战最后一波，出生在离主角远的一头、落到地面。
- 摄像机"录下来的你"要出一只倒带鬼：`HiddenMobs.make("rewinder")`，加进房间就行（`room.level.add_child`，位置自己设）。

在两个工厂没写好之前，关卡用第一关的爬虫顶着，不会报错。

## 5. 三个小机制挂在哪（三个主要bug修复会话）
- 关卡给 `mech` 是 `pause` / `skip` / `rewind` / `exam` 的房间各建一个机制节点，挂在房间下：
  ```
  var m = load("res://scripts/hidden/mech_pause.gd").new()   # skip、rewind 同理
  m.set("room", room)      # HiddenRoom
  room.add_child(m)
  ```
  exam（R16）三个都挂，参数调温和：暂停冷却短、跳帧间隔长、倒带只倒 1 秒。脚本里看 `room.data["mech"] == "exam"`。
- 只在 `room.active` 时运行。房间不活跃时恢复原状（解除暂停、a 帧打开）。
- 暂停键的位置：`room.data["pause_buttons"]`。按钮节点（被打、被踩触发）由机制自己建。
- 跳帧：`room.plats("a")` / `room.plats("b")`，设 `frame_on`；怪跳位置自己处理。
- 倒带：`room.actors()` 每帧记位置和速度，倒的时候放回去。主角不倒。
- 文件没写好之前，关卡检查 `ResourceLoader.exists`，没有就跳过，不报错。

## 6. Boss 房（游戏设计会话）
- R17 是 Boss 房，两屏宽、一屏半高。关卡只建外墙和一条地面。
- 主角第一次进 R17 时，关卡做下面的事：
  ```
  var boss = load("res://scripts/hidden/boss_rec.gd").new()
  boss.set("room", room)          # 有 rect、level
  room.add_child(boss)
  boss.connect("defeated", level._on_boss_defeated)
  ```
- 场地里的东西（磁鼓、压带轮、磁带传送带、消磁头、上方的暖冷平台）都由 Boss 脚本自己建。
  - 平台可以用 `room.level.add_plat(kind, x0, x1, y)` 建 HPlat，自动套用光照规则；
  - 灯光用 `MemoryLight`。
- 门：R17 进门后闸门落下，打完开门。关卡等 `defeated` 信号，然后开右门去 R18 真结局。
- 血条、名字卡用你熟悉的 BossArena / Hud 那套，或者自己画都行，别和关卡的横幅叠在屏幕中间那一条（y 108～142）。

## 8. 测试入口
- 场景：`scenes/hidden/hidden_level.tscn`
- 参数（`--` 后面）：
  - `--hroom=R6`：从 R6 的入口开始。不带就从 R0 开始；
  - `--hclips=all`：两段片段都算拿到，电视门开着；
  - `--hgod`：主角无敌、马灯不掉血；
  - `--hquit=600`：600 物理帧后自己退出（物理是每秒 120 帧）；
  - `--hauto`：自动驾驶（后面做）。
- 例子：
  ```
  SCRAP_SETTINGS_PATH=… SCRAP_BESTIARY_PATH=… SCRAP_RUN_PATH=… SCRAP_PROGRESS_PATH=… SCRAP_ACHIEVE_PATH=… \
  Godot --headless --fixed-fps 60 --path . --log-file <scratchpad>/h.log scenes/hidden/hidden_level.tscn -- --hroom=R6 --hgod --hquit=1200
  ```
- 开发者模式：F8 打开面板以后按 8，直接进隐藏关。主线流程先不动。
